# KULTURGUT.T website

This static public concept page presents the planned cross-municipal association in Lassing, Selzthal and Liezen. The German copy follows the approved public concept in the vault. Internal budgets, unconfirmed performers and event dates are excluded.

## Design

The user selected the supplied blue organic logo on 21 September 2026. Its original JPEG is preserved in assets/logo-blue.jpg. It overlaps the upper left edge of a continuous paper-colored content area, following the supplied layout sketch. Pale blue surrounds the page. Georgia headings and Arial body text provide a print-oriented hierarchy without external font requests. The small music illustration is an original inline SVG, not a photograph of a performer or venue.

The site is HTML and CSS without JavaScript, dependencies, analytics or forms. Native anchor navigation, a skip link and visible keyboard focus remain available. Mobile navigation precedes the logo to avoid overlap. No operating-association contact details have been supplied; the footer identifies the existing concept preview. A full association imprint remains to be completed before the association launch.

# Kulturgut.t website

This repository contains the public concept preview requested by the project owner. The German one-page concept in `index.html` is the published text. It describes a planned association, initial room commitments in Lassing, Selzthal and Liezen, temporary use of vacant spaces, inclusion and family participation, afternoon concerts, music and theatre, and regional and international artists.

Artist conversations and exhibitions are excluded from this initial description. Accessibility is an objective subject to venue verification, not a certification. Funding is prospective, not awarded.

The site uses local HTML, CSS and a draft logo. No JavaScript, analytics, forms, external fonts or runtime dependencies are used. Hosting is GitHub Pages from the main branch root. The repository contains only the website and its maintenance notes.

## Design

The green egg logo is a provisional generated design, not an approved final mark. The existing responsive layout is retained for reviewing the text on phones. Colors and typography remain subject to review. Copy is German, with readable paragraph lengths, semantic headings, native anchor links and visible keyboard focus.

## Local preview

Run `python -m http.server 5180 --bind 127.0.0.1` from this directory.
